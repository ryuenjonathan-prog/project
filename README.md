# Phone LiDAR

Android-приложение, которое превращает обычную камеру телефона (проверялось под Xiaomi 13)
в «псевдо-лидар»: в реальном времени строит цветное 3D-облако точек окружающего пространства.

## Как это работает

У Xiaomi 13 нет настоящего LiDAR/ToF-датчика, поэтому глубина считается программно через
**Google ARCore Depth API**: ARCore отслеживает движение телефона (SLAM) и по смещению
кадров вычисляет карту глубины (~160×120 точек, до ~5–8 м).

Каждый кадр приложение:
1. берёт сырую карту глубины и карту уверенности (`acquireRawDepthImage16Bits`);
2. отбрасывает ненадёжные пиксели;
3. переводит каждый пиксель в 3D-точку через параметры камеры и положение телефона в мире;
4. раскрашивает точку цветом из камеры;
5. складывает в общее облако с вокселной сеткой 1,5 см (без дублей), до 1,5 млн точек;
6. рисует облако через OpenGL поверх камеры или в отдельном 3D-виде.

## Установка без ПК

1. На телефоне откройте страницу репозитория → **Releases** → последняя сборка.
2. Скачайте `PhoneLidar.apk` и откройте его, разрешите «установку из неизвестных источников»
   для браузера (MIUI/HyperOS спросит сам).
3. При первом запуске приложение может попросить установить
   **Google Play Services for AR** из Play Маркета — согласитесь.

Каждый push в репозиторий автоматически собирает новый APK (GitHub Actions,
`.github/workflows/build-apk.yml`). Новые версии ставятся поверх старых.

## Использование

- Медленно поводите телефоном, пока не пойдёт трекинг, затем плавно обходите объект/комнату.
- **Пауза/Скан** — остановить или продолжить набор точек.
- **3D вид** — посмотреть облако со стороны: палец — вращение, щипок — масштаб.
- **Очистить** — начать заново.
- **Сохранить** — файл `scan_*.ply` в папку «Загрузки». Открывается в MeshLab,
  CloudCompare, Blender, а на телефоне — например, в приложениях для просмотра PLY/3D.

## Ограничения

- Это не настоящий лидар: точность порядка 1–5 см на 1–3 м, дальше шумнее.
- Плохо работает на однотонных стенах, стекле, зеркалах и в темноте.
- Нужен телефон с поддержкой ARCore Depth (Xiaomi 13 в списке поддерживаемых).
