# Phone LiDAR — 3D-сканер комнаты

Android-приложение, которое превращает камеру телефона (делалось под Xiaomi 13) в 3D-сканер:
вы обходите комнату, на экране в реальном времени нарастает 3D-сетка, а в конце
модель можно скачать в **GLB / OBJ / PLY**.

## Установка без ПК

1. На телефоне откройте страницу репозитория → **Releases** → самая верхняя сборка.
2. Скачайте `PhoneLidar.apk`, откройте, разрешите установку из неизвестных источников.
3. При первом запуске приложение может попросить **Google Play Services for AR** — установите.

Каждый push автоматически собирает новый APK (`.github/workflows/build-apk.yml`),
новые версии ставятся поверх старых.

## Как сканировать

1. Нажмите красную кнопку ● — начнётся запись.
2. Медленно ведите телефон по стенам, полу, мебели с расстояния 0,5–3 м. Отсканированные
   поверхности покрываются цветной сеткой (цвет = направление поверхности).
3. Нажмите ■ — запись остановится, и откроется 3D-вид готовой модели
   (палец — вращать, щипок — зум, два пальца — сдвиг, двойной тап — центрировать).
4. Можно продолжить запись, если что-то пропустили.
5. **Скачать** → формат → файл появится в `Загрузки/PhoneLidar`, его можно сразу открыть
   или отправить.

| Формат | Для чего |
|---|---|
| GLB | Универсальная 3D-модель с цветами: просмотрщики на телефоне, Blender, Windows 3D Viewer, веб |
| OBJ | Blender, 3ds Max, Unity (цвета вершин в формате `v x y z r g b`) |
| PLY | MeshLab, CloudCompare, Blender |

Кнопка «Стиль» переключает вид сетки: **Цвет** (реальные цвета), **Глина** (серая модель
со светом), **Нормали** (радужная — удобно видеть форму).

## Как это работает

- **Глубина:** у Xiaomi 13 нет LiDAR/ToF-датчика, поэтому глубину вычисляет Google ARCore Depth API
  по движению камеры (≈160×120 точек на кадр, до ~5 м). Плюс SLAM-трекинг положения телефона.
- **Слияние (TSDF):** каждая карта глубины вплавляется в разреженный воксельный объём
  (воксель 2 см, блоки 8³ создаются только около поверхностей). Шум усредняется
  по сотням кадров, поэтому поверхность получается гладкой.
- **Сетка (Surface Nets):** объём поделён на чанки 64 см; перестраиваются только изменённые,
  поэтому сетка растёт в реальном времени.
- **Скорость:** вся тяжёлая работа идёт в отдельном потоке, а GL-поток только рисует. Камера
  запускается в режиме 60 FPS, если телефон его поддерживает вместе с Depth API (счётчик
  FPS вверху справа показывает фактическое значение).

## Ограничения

- Это не настоящий лидар: точность ~1–5 см, хуже на больших расстояниях.
- Плохо сканируются однотонные белые стены, стекло, зеркала, тёмные помещения.
- Лимит ~25 000 блоков (обычно хватает на большую комнату); при достижении запись остановится.
